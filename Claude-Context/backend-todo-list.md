## ⚠️ 架构限制说明

### 设计原则：
- ✅ **极简架构**：仅作为 OpenAI API 的中转层
- ✅ **无状态设计**：不使用数据库，所有数据在内存中处理
- ✅ **同步处理**：直接调用 OpenAI API，不使用消息队列
- ✅ **安全第一**：保护 OpenAI API Key，防止泄露

### 功能限制：
- ❌ **无图片处理**：直接传递原始图片给 OpenAI
- ❌ **无消息队列**：同步处理，不使用异步队列
- ❌ **无数据库**：不持久化存储任何数据
- ❌ **无复杂功能**：仅保留核心的评论生成功能
